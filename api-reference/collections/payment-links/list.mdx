Returns your business's payment links, newest first. `status` is the effective status: an `open` link past its `expiresAt` reads, and filters, as `expired`.

<Info>**Scope** `collections:read` · rate limit `collections_read` (120/min, burst 40) · needs collections enabled on your business</Info>

<Headers />

## Query parameters

<ParamField query="limit" type="integer" default="10">
  Page size. Values outside 1–100 are clamped to that range.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of links to skip.
</ParamField>

<ParamField query="status" type="string">
  Only links with this effective status: `open`, `detected`, `paid` or `expired`. Any other value returns `400 INVALID_PARAMETER`.
</ParamField>

<ParamField query="buyerId" type="string">
  Only links issued to this buyer (UUID). A buyer of another business returns an empty list.
</ParamField>

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `INVALID_PARAMETER` | `status` is not a recognised value, or `buyerId` is not a UUID. |
| `400` | `ENTITY_REQUIRED` | The key's owner belongs to more than one business and `X-Teel-Entity-Id` is missing. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `collections:read`. |
| `403` | `COLLECTIONS_NOT_ENABLED` | Collections is not enabled for your business. |
| `429` | `RATE_LIMITED` | `collections_read` budget exhausted. Wait for `Retry-After`. |
