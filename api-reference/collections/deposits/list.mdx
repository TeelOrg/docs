Returns bank transfers into your [receiving accounts](/api-reference/collections/virtual-accounts/list), newest first. Subscribe to `collections.deposit.received` instead of polling; it fires when a deposit is credited.

<Info>**Scope** `collections:read` · rate limit `collections_read` (120/min, burst 40)</Info>

<Headers />

## Query parameters

<ParamField query="limit" type="integer" default="10">
  Page size. Values outside 1–100 are clamped to that range.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of deposits to skip.
</ParamField>

<ParamField query="virtualAccountId" type="string">
  Only deposits into this receiving account (UUID). An account of another business returns an empty list.
</ParamField>

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `INVALID_PARAMETER` | `virtualAccountId` is not a UUID. |
| `400` | `ENTITY_REQUIRED` | The key's owner belongs to more than one business and `X-Teel-Entity-Id` is missing. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `collections:read`. |
| `429` | `RATE_LIMITED` | `collections_read` budget exhausted. Wait for `Retry-After`. |
