A buyer is a payer you invoice: a name and email, plus their own on-chain receiving address once one is minted. The same buyer can pay both stablecoin and bank-transfer links.

<Info>**Scope** `collections:read` · rate limit `collections_read` (120/min, burst 40)</Info>

## Query parameters

<ParamField query="limit" type="integer" default="10">
  Page size. Values outside 1–100 are clamped to that range.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of buyers to skip.
</ParamField>

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `ENTITY_REQUIRED` | The key's owner belongs to more than one business and `X-Teel-Entity-Id` is missing. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `collections:read`. |
| `429` | `RATE_LIMITED` | `collections_read` budget exhausted. Wait for `Retry-After`. |
