Returns `404` if the ID isn't yours. A buyer of another business looks the same as one that doesn't exist.

<Info>**Scope** `collections:read` · rate limit `collections_read` (120/min, burst 40)</Info>

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `INVALID_PARAMETER` | `id` is not a UUID. |
| `400` | `ENTITY_REQUIRED` | The key's owner belongs to more than one business and `X-Teel-Entity-Id` is missing. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `collections:read`. |
| `404` | `NOT_FOUND` | No such buyer for your business. |
| `429` | `RATE_LIMITED` | `collections_read` budget exhausted. Wait for `Retry-After`. |
