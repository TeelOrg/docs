---
title: Sync User
api: POST https://api.teel.finance/api/users/sync
description: Create or update a user from Auth0
---

Creates a new user record or updates an existing one based on the dashboard identity. Called after a user authenticates so the local user record is in sync.

<Note>
  Used by the Teel dashboard — not part of the partner API surface. Partners using `sk_` keys cannot call this endpoint.
</Note>

## Headers

<ParamField header="Authorization" type="string" required>
  Dashboard session token (JWT).
</ParamField>

## Response
<ResponseField name="id" type="string">
  Unique user identifier.
</ResponseField>

<ResponseField name="email" type="string">
  User's email address.
</ResponseField>

<ResponseField name="name" type="string">
  User's display name.
</ResponseField>

<ResponseField name="auth0Id" type="string">
  The user's Auth0 identifier.
</ResponseField>

<ResponseField name="created" type="boolean">
  Whether a new user record was created (`true`) or an existing one was updated (`false`).
</ResponseField>

<ResponseExample>
```json 200
{
  "id": "usr_abc123",
  "email": "user@example.com",
  "name": "Jane Smith",
  "auth0Id": "auth0|abc123def456",
  "created": true
}
```
</ResponseExample>
