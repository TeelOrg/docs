Returns a representative rate for a corridor. Nothing is reserved or locked; use it for display, then quote again before you execute.

<Info>**Scope** `quotes:read` · rate limit `quotes_read` (120/min, burst 40) · each currency must be in your business's payouts scope</Info>

<Headers />

## Query parameters

<ParamField query="sourceCurrency" type="string" required>
  ISO 4217 code of the source currency.
</ParamField>
<ParamField query="targetCurrency" type="string" required>
  ISO 4217 code of the destination currency.
</ParamField>
<ParamField query="amount" type="number" required>
  Source amount. Must be `> 0`.
</ParamField>

## Response

<ResponseField name="success" type="boolean">`true`.</ResponseField>
<ResponseField name="data" type="object">
  The indicative route, or `null` when there is none.

    <FiatRouteFields />
  </Expandable>
</ResponseField>
<ResponseField name="message" type="string">`No route available` when `data` is `null`.</ResponseField>
