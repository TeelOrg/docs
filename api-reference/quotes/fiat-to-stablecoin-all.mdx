Returns every route for converting fiat into a stablecoin. Send `amount` to fix the fiat, or `targetAmount` to fix the stablecoin delivered.

<Info>**Scope** `quotes:read` · rate limit `quotes_read` (120/min, burst 40) · each currency must be in your business's payouts scope</Info>

## Query parameters

<ParamField query="sourceCurrency" type="string" required>
  ISO 4217 code of the fiat you pay in.
</ParamField>
<ParamField query="amount" type="number">
  Fiat amount. Required unless you send `targetAmount`.
</ParamField>
<ParamField query="targetAmount" type="number">
  Exact stablecoin amount delivered.
</ParamField>
<ParamField query="cryptoTicker" type="string">
  Stablecoin to deliver, for example `USDCPOLYGON`.
</ParamField>
<ParamField query="userPaymentMethodId" type="string">
  Your funding payment method. Prices the quote from that source, including a held balance's funding fee. Must be yours.
</ParamField>
<ParamField query="recipientPaymentMethodId" type="string">
  Recipient payment method to price delivery to. Must be yours.
</ParamField>
<ParamField query="fundingRail" type="string">
  Held-balance sources only. Only routes funded on this rail. A rail the source cannot fund on is `422 FUNDING_RAIL_UNSUPPORTED`.
</ParamField>
