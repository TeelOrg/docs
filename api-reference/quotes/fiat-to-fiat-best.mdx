Returns the single best route for converting one fiat currency to another. When no route is available, the call still succeeds with `data: null` and a `noRouteReason`.

<Info>**Scope** `quotes:read` · rate limit `quotes_read` (120/min, burst 40) · each currency must be in your business's payouts scope</Info>

<Headers />

## Query parameters

<ParamField query="sourceCurrency" type="string" required>
  ISO 4217 code of the source currency.
</ParamField>
<ParamField query="targetCurrency" type="string" required>
  ISO 4217 code of the destination currency.
</ParamField>
<ParamField query="amount" type="number" required>
  Source amount. Must be `> 0`.
</ParamField>
<ParamField query="userPaymentMethodId" type="string">
  Your funding payment method. Prices the quote from that source, including a held balance's funding fee. Must be yours.
</ParamField>
<ParamField query="recipientId" type="string">
  Recipient to price delivery to, using their payment methods. Ignored when `recipientPaymentMethodId` is set. Must be yours.
</ParamField>
<ParamField query="recipientPaymentMethodId" type="string">
  Recipient payment method to price delivery to. Must be yours.
</ParamField>
<ParamField query="payoutRail" type="string">
  Only routes that pay this rail of the payout currency, for example `instapay` or `ach`. A value that is not a rail of the currency is `400 INVALID_PAYOUT_RAIL`.
</ParamField>
<ParamField query="fundingRail" type="string">
  Held-balance sources only. Only routes funded on this rail. A rail the source cannot fund on is `422 FUNDING_RAIL_UNSUPPORTED`.
</ParamField>

## Response

<ResponseField name="success" type="boolean">`true`.</ResponseField>
<ResponseField name="data" type="object">
  The best route, or `null` when there is none.
  <Expandable title="data">
    <FiatRouteFields />
    <RouteExtras />
  </Expandable>
</ResponseField>
<ResponseField name="noRouteReason" type="string">
  Present only when `data` is empty: `provider_corridor_not_enabled`, `corridor_unsupported`, `amount_out_of_range`, `provider_kyc_required`, `payout_rail_unavailable`, `provider_down`, `rate_unavailable`, `settlement_unavailable` or `unknown`.
</ResponseField>
<ResponseField name="warnings" type="object">
  Present when the route is responding slowly. `providerSlow.p95LatencyMs` is its recent 95th-percentile response time in milliseconds.
</ResponseField>
