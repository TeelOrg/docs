Returns every available route for converting stablecoin into a fiat payout. Send `usdcAmount` to fix what you sell, or `targetAmount` to fix what the recipient receives (exact output, one quote per route and rail, cheapest first).

<Info>**Scope** `quotes:read` · rate limit `quotes_read` (120/min, burst 40) · each currency must be in your business's payouts scope</Info>

## Query parameters

<ParamField query="payoutCurrency" type="string" required>
  ISO 4217 code of the payout currency.
</ParamField>
<ParamField query="usdcAmount" type="number">
  Stablecoin amount to sell. Send this or `targetAmount`.
</ParamField>
<ParamField query="targetAmount" type="number">
  Exact amount the recipient receives. Send this or `usdcAmount`.
</ParamField>
<ParamField query="cryptoTicker" type="string">
  With `targetAmount`: the stablecoin to price on, for a source that is not a wallet. An unknown ticker is `400`.
</ParamField>
<ParamField query="userPaymentMethodId" type="string">
  Your funding payment method. Prices the quote from that source, including a held balance's funding fee. Must be yours.
</ParamField>
<ParamField query="recipientId" type="string">
  Recipient to price delivery to, using their payment methods. Ignored when `recipientPaymentMethodId` is set. Must be yours.
</ParamField>
<ParamField query="recipientPaymentMethodId" type="string">
  Recipient payment method to price delivery to. Must be yours.
</ParamField>
<ParamField query="payoutRail" type="string">
  Only routes that pay this rail of the payout currency, for example `instapay` or `ach`. A value that is not a rail of the currency is `400 INVALID_PAYOUT_RAIL`.
</ParamField>

## Response

<ResponseField name="success" type="boolean">`true`.</ResponseField>
<ResponseField name="data" type="array">
  One quote per route.
  <Expandable title="data[]">
    <OfframpQuoteFields />
    <RouteExtras />
  </Expandable>
</ResponseField>
<ResponseField name="payoutRailOptions" type="array">
  One entry per rail the routes in `data` pay, when the rail has a standard arrival. Each carries the best route on that rail: `rail`, `label`, `protocol`, `bridgingAsset`, `fundingRail`, `fromAmount`, `toAmount`, `exchangeRate`, `flatFees`, `expectedArrivalAt`, and the flags `fastest` (earliest arrival) and `bestRate` (the first option). To lock one, send its `protocol` as `routeProtocol`, `rail` as `payoutRail` and, when not empty, `bridgingAsset` and `fundingRail` on execute.
</ResponseField>
