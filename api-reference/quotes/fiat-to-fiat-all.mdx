Returns every route for converting one fiat currency to another, best first. Send `amount` to fix the source, or `targetAmount` to fix what the recipient receives. When no route is available, `data` is empty and `noRouteReason` says why.

<Info>**Scope** `quotes:read` · rate limit `quotes_read` (120/min, burst 40) · each currency must be in your business's payouts scope</Info>

## Query parameters

<ParamField query="sourceCurrency" type="string" required>
  ISO 4217 code of the source currency.
</ParamField>
<ParamField query="targetCurrency" type="string" required>
  ISO 4217 code of the destination currency.
</ParamField>
<ParamField query="amount" type="number">
  Source amount. Required unless you send `targetAmount`.
</ParamField>
<ParamField query="targetAmount" type="number">
  Exact amount the recipient receives. Must be `> 0`.
</ParamField>
<ParamField query="amountIs" type="string">
  `spend`: `amount` is the whole cost leaving the source, including a held balance's funding fee. A decimal within the source currency's precision. Any other value, or `spend` with `targetAmount`, is `400 AMOUNT_IS_INVALID`.
</ParamField>
<ParamField query="userPaymentMethodId" type="string">
  Your funding payment method. Prices the quote from that source, including a held balance's funding fee. Must be yours.
</ParamField>
<ParamField query="recipientId" type="string">
  Recipient to price delivery to, using their payment methods. Ignored when `recipientPaymentMethodId` is set. Must be yours.
</ParamField>
<ParamField query="recipientPaymentMethodId" type="string">
  Recipient payment method to price delivery to. Must be yours.
</ParamField>
<ParamField query="payoutRail" type="string">
  Only routes that pay this rail of the payout currency, for example `instapay` or `ach`. A value that is not a rail of the currency is `400 INVALID_PAYOUT_RAIL`.
</ParamField>
<ParamField query="fundingRail" type="string">
  Held-balance sources only. Only routes funded on this rail. A rail the source cannot fund on is `422 FUNDING_RAIL_UNSUPPORTED`.
</ParamField>

## Response

<ResponseField name="success" type="boolean">`true`.</ResponseField>
<ResponseField name="data" type="array">
  Routes, best first. A route that cannot be used for this request is listed with `enabled: false`.
  <Expandable title="data[]">
    <FiatRouteFields />
    <RouteExtras />
  </Expandable>
</ResponseField>
<ResponseField name="payoutRailOptions" type="array">
  One entry per rail the routes in `data` pay, when the rail has a standard arrival. Each carries the best route on that rail: `rail`, `label`, `protocol`, `bridgingAsset`, `fundingRail`, `fromAmount`, `toAmount`, `exchangeRate`, `flatFees`, `expectedArrivalAt`, and the flags `fastest` (earliest arrival) and `bestRate` (the first option). To lock one, send its `protocol` as `routeProtocol`, `rail` as `payoutRail` and, when not empty, `bridgingAsset` and `fundingRail` on execute.
</ResponseField>
<ResponseField name="noRouteReason" type="string">
  Present only when `data` is empty: `provider_corridor_not_enabled`, `corridor_unsupported`, `amount_out_of_range`, `provider_kyc_required`, `payout_rail_unavailable`, `provider_down`, `rate_unavailable`, `settlement_unavailable` or `unknown`.
</ResponseField>
<ResponseField name="amountIs" type="string">`spend`, only when you sent `amountIs=spend`.</ResponseField>
