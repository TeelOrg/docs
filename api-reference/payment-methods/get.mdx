---
title: Get Payment Method
api: GET /api/payment-methods/{id}
description: Get a payment method by ID
---

<Note>
  Used by the Teel dashboard — not part of the partner API surface. Partners using `sk_` keys cannot call this endpoint.
</Note>

## Headers

<ParamField header="Authorization" type="string" required>
  Dashboard session token (JWT).
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Payment method ID.
</ParamField>
## Response

<ResponseExample>
```json
{
  "id": "pm_abc123",
  "type": "bank_transfer",
  "bankName": "Chase",
  "accountNumber": "****7890",
  "currency": "USD"
}
```
</ResponseExample>
