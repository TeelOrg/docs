---
title: List Payment Methods
api: GET /api/payment-methods
description: List user's payment methods
---

<Note>
  Used by the Teel dashboard — not part of the partner API surface. Partners using `sk_` keys cannot call this endpoint.
</Note>

## Headers

<ParamField header="Authorization" type="string" required>
  Dashboard session token (JWT).
</ParamField>

## Response

<ResponseExample>
```json
[
  {
    "id": "pm_abc123",
    "type": "bank_transfer",
    "bankName": "Chase",
    "accountNumber": "****7890",
    "currency": "USD"
  }
]
```
</ResponseExample>
