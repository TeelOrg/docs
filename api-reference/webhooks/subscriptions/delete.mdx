---
title: Delete subscription
api: DELETE /api/webhooks/subscriptions/{id}
description: Delete a webhook subscription
---

Cascades — deletes pending + historical deliveries. To pause without losing the audit trail, use [Update](/api-reference/webhooks/subscriptions/update) with `status: "paused"`.

<Info>**Scope** `webhooks:write` · rate limit `default` (60/min, burst 20)</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Subscription UUID.
</ParamField>

## Response

<ResponseField name="deleted" type="boolean">
  Always `true` on success.
</ResponseField>

<ResponseExample>
```json 200
{ "deleted": true }
```
</ResponseExample>

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `INVALID_PARAMETER` | `id` is not a UUID. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `webhooks:write`. |
| `404` | `WEBHOOK_SUBSCRIPTION_NOT_FOUND` | The subscription does not exist or is not yours. |
| `429` | `RATE_LIMITED` | Rate limit hit. Wait for `Retry-After`. |
