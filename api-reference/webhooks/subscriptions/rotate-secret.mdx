---
title: Rotate signing secret
api: POST /api/webhooks/subscriptions/{id}/rotate-secret
description: Mint a new signing secret and invalidate the previous one
---

Mints a new `whsec_…` secret and returns it once. **The previous secret is invalidated immediately — there is no overlap window.**

If you need overlap (e.g. rolling deploys), use this flow:

1. [Pause](/api-reference/webhooks/subscriptions/update) the subscription.
2. Rotate the secret here.
3. Deploy your verifier with the new secret.
4. Unpause the subscription via Update.

<Info>**Scope** `webhooks:write` · rate limit `rotate_secret` (3/min, burst 3)</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Subscription UUID.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Subscription UUID.
</ResponseField>

<ResponseField name="secret" type="string">
  The new signing secret in plaintext. Returned only here — store it immediately.
</ResponseField>

<ResponseField name="secretPrefix" type="string">
  First few characters of the new secret.
</ResponseField>

The other fields (`userId`, `url`, `events`, `status`, `label`, `lastSuccessAt`, `lastFailureAt`, `createdAt`, `updatedAt`) match the shape on [List subscriptions](/api-reference/webhooks/subscriptions/list).

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `INVALID_PARAMETER` | `id` is not a UUID. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `webhooks:write`. |
| `404` | `WEBHOOK_SUBSCRIPTION_NOT_FOUND` | The subscription does not exist or is not yours. |
| `429` | `RATE_LIMITED` | Rate limit hit. Wait for `Retry-After`. |
