---
title: Update subscription
api: PATCH /api/webhooks/subscriptions/{id}
description: Update a webhook subscription
---

All fields are optional — any field you omit stays unchanged. Returns the updated subscription. Pausing stops new deliveries from being enqueued; in-flight retries continue.

<Info>**Scope** `webhooks:write` · rate limit `default` (60/min, burst 20)</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Subscription UUID.
</ParamField>

## Request body

<ParamField body="url" type="string">
  New endpoint URL. Same validation rules as [Create](/api-reference/webhooks/subscriptions/create).
</ParamField>

<ParamField body="events" type="string[]">
  New event allow-list. Replaces the existing list. Adding a `collections.*` event needs the `collections:read` scope on this key, or returns `403 INSUFFICIENT_SCOPE`.
</ParamField>

<ParamField body="status" type="string">
  `active` or `paused`. `disabled` is reserved for ops-side use and not user-settable.
</ParamField>

<ParamField body="label" type="string">
  New label.
</ParamField>

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `INVALID_PARAMETER` | `id` is not a UUID. |
| `400` | `INVALID_JSON` | The body is not valid JSON, or `url` is not a URL. |
| `400` | `INVALID_REQUEST` | `url` fails the [Create](/api-reference/webhooks/subscriptions/create) rules, `events` is empty or names an unknown event type, or `status` is not `active` or `paused`. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `webhooks:write`, or `events` includes a `collections.*` event and the key lacks `collections:read`. |
| `404` | `WEBHOOK_SUBSCRIPTION_NOT_FOUND` | The subscription does not exist or is not yours. |
| `429` | `RATE_LIMITED` | Rate limit hit. Wait for `Retry-After`. |
