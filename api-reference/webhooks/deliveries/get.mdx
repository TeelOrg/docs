---
title: Get delivery
api: GET /api/webhooks/deliveries/{id}
description: Fetch one webhook delivery by ID
---

Single delivery row. Useful after [Replay](/api-reference/webhooks/deliveries/replay) to poll its outcome.

<Info>**Scope** `webhooks:read` · rate limit `default` (60/min, burst 20)</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Delivery UUID.
</ParamField>

## Response

Same shape as one row on [List deliveries](/api-reference/webhooks/deliveries/list).

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `INVALID_PARAMETER` | `id` is not a UUID. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `webhooks:read`. |
| `404` | `WEBHOOK_DELIVERY_NOT_FOUND` | The delivery does not exist or is not yours. |
| `429` | `RATE_LIMITED` | Rate limit hit. Wait for `Retry-After`. |
