---
title: Get recipient
api: GET /api/recipients/{id}
description: Fetch a single recipient by ID
---

Returns `404` if the ID isn't yours.

<Info>**Scope** `recipients:read` · rate limit `default` (60/min, burst 20)</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Recipient UUID.
</ParamField>

## Errors

| Status | Code | When |
|---|---|---|
| `400` | `INVALID_PARAMETER` | `id` is not a UUID. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `recipients:read`. |
| `404` | `RECIPIENT_NOT_FOUND` | The recipient does not exist or is not yours. Both answer the same. |
| `429` | `RATE_LIMITED` | Per-key rate limit. Wait for `Retry-After`. |
