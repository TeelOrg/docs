---
title: Delete recipient
api: DELETE /api/recipients/{id}
description: Delete a recipient
---

Removes the recipient. Past payouts that reference the recipient are unaffected.

<Info>**Scope** `recipients:write` · rate-limited</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Recipient UUID.
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation string. Always `"Recipient deleted successfully"` on success.
</ResponseField>

<ResponseExample>
```json 200
{ "message": "Recipient deleted successfully" }
```
</ResponseExample>
