---
title: Delete recipient
api: DELETE /api/recipients/{id}
description: Delete a recipient
---

Removes the recipient and its counterparty rows across providers. Past payouts that reference the recipient are unaffected.

## Headers

<ParamField header="Authorization" type="string" required>
  `Bearer sk_test_…` (sandbox) or `Bearer sk_live_…` (production).
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Recipient UUID.
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation string. Always `"Recipient deleted successfully"` on success.
</ResponseField>

<ResponseExample>
```json 200
{ "message": "Recipient deleted successfully" }
```
</ResponseExample>
