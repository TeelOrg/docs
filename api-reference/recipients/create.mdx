---
title: Create recipient
api: POST /api/recipients
description: Register a recipient.
---

Body is a common section + a type-specific section keyed on `transferType`. Call [`GET /recipients/requirements`](/api-reference/recipients/requirements) first for the live field list.

<Info>**Scope** `recipients:write` · rate-limited</Info>

## Headers

<ParamField header="Authorization" type="string" required>

</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Optional. Up to 255 url-safe characters (≥8). Replays the cached response within 24 hours; mismatched bodies on the same key return `409 IDEMPOTENCY_KEY_REUSED`.
</ParamField>

### Partial setup (207)

The recipient exists, so do not create it again.

<ResponseField name="recipient" type="object">The saved recipient, with the fields above.</ResponseField>
<ResponseField name="provisioningError" type="string">Present when setup failed for some routes. Display text that may change; never branch on it.</ResponseField>
<ResponseField name="retryable" type="boolean">Set with `provisioningError`. `true` when every failure was temporary: call [`POST /recipients/{id}/retry`](/api-reference/recipients/retry) to complete setup. `false`: contact support.</ResponseField>

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `INVALID_REQUEST` | Body malformed, a field has the wrong shape, or a payment method has no `currency`. |
| `400` | `VALIDATION_FAILED` | Field values break the corridor's schema. `details.violations` lists each field. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `recipients:write`. |
| `403` | `FORBIDDEN` | The key's owner is not a member of the business named in `X-Teel-Entity-Id`, or belongs to no business. |
| `409` | `IDEMPOTENCY_KEY_REUSED` / `IDEMPOTENCY_REQUEST_IN_FLIGHT` | Idempotency conflict. |
| `422` | `ADDRESS_SCREENING_BLOCKED` / `ADDRESS_SCREENING_UNDER_REVIEW` | Screening refused a wallet address. Nothing was saved. |
| `503` | `ADDRESS_SCREENING_UNAVAILABLE` | A wallet address could not be screened. Nothing was saved; retry. |
