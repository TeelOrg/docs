---
title: Update recipient
api: PUT /api/recipients/{id}
description: Update a recipient. Any field you omit stays unchanged.
---

All fields are optional — only the fields you include are written. To change recipient type (fiat ↔ stablecoin), submit the relevant `transferType` plus the corresponding `paymentMethods` (fiat) or `walletAddresses` (stablecoin).

## Headers

<ParamField header="Authorization" type="string" required>
  `Bearer sk_test_…` (sandbox) or `Bearer sk_live_…` (production).
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Recipient UUID.
</ParamField>

## Request body

<ParamField body="email" type="string">
  New email.
</ParamField>

<ParamField body="businessName" type="string">
  New legal business name.
</ParamField>

<ParamField body="firstName" type="string">
  New individual first name.
</ParamField>

<ParamField body="lastName" type="string">
  New individual last name.
</ParamField>

<ParamField body="country" type="string">
  New ISO 3166-1 alpha-2 country code. Changing this can change which provider services the recipient.
</ParamField>

<ParamField body="phone" type="string">
  E.164 phone number.
</ParamField>

<ParamField body="address" type="object">
  New postal address.
</ParamField>

<ParamField body="externalReference" type="object">
  Replaces the stored object. Send `{}` to clear.
</ParamField>

<Tabs>
  <Tab title="Fiat (bank)">
    <ParamField body="transferType" type="string">Set to `"fiat"`.</ParamField>
    <ParamField body="paymentMethods" type="object[]">
      Full replacement of the recipient's payment methods. See [Create recipient](/api-reference/recipients/create) for the per-rail fields.
    </ParamField>
  </Tab>
  <Tab title="Stablecoin (wallet)">
    <ParamField body="transferType" type="string">Set to `"stablecoin"`.</ParamField>
    <ParamField body="walletAddresses" type="object">
      Full replacement of the chain → address map.
    </ParamField>
  </Tab>
</Tabs>
