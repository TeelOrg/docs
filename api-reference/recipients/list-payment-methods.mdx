---
title: List recipient payment methods
api: GET /api/recipients/{id}/payment-methods
description: List a recipient's active payment methods
---

Returns the recipient's active payment methods, newest first. Pass a payment method's `id` as `recipientPaymentMethodId` when you [execute a payout](/api-reference/payouts/execute).

<Info>**Scope** `recipients:read`</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  `Bearer <key>`, where `<key>` is your API key.
</ParamField>

<ParamField header="X-Teel-Entity-Id" type="string">
  Only needed when the key's owner belongs to more than one business. The UUID of the business this request acts for. Without it, such a key gets `400 ENTITY_REQUIRED`.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Recipient UUID.
</ParamField>

## Errors

| Status | Code | Meaning |
| --- | --- | --- |
| `400` | `INVALID_PARAMETER` | `id` is not a UUID. |
| `400` | `ENTITY_REQUIRED` | The key's owner belongs to more than one business and `X-Teel-Entity-Id` is missing. |
| `401` | `UNAUTHORIZED` | Missing/invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `recipients:read`. |
| `404` | `RECIPIENT_NOT_FOUND` | The recipient doesn't exist or isn't yours. |
| `429` | `RATE_LIMITED` | Per-key rate limit exhausted. Wait for `Retry-After`. |
