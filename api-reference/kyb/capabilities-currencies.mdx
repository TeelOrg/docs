---
title: Get Supported Currencies
api: GET https://api.teel.finance/api/kyb/capabilities/currencies
description: Get the list of supported currencies across all providers
---

Returns the flat, sorted list of fiat currency codes supported by the platform.

<Note>
  This endpoint requires authentication (dashboard Auth0 JWT). For an
  unauthenticated, partner-facing view — including payment rails, onramp/offramp
  direction, and per-currency amount bounds — use the public
  [coverage endpoint](/api-reference/config/coverage).
</Note>

## Response

<ResponseField name="success" type="boolean">
  `true` when the request succeeded.
</ResponseField>

<ResponseField name="currencies" type="array">
  Sorted, de-duplicated array of ISO 4217 currency codes the platform supports.
</ResponseField>

<ResponseExample>
```json 200
{
  "success": true,
  "currencies": ["EUR", "GBP", "IDR", "MXN", "PHP", "USD"]
}
```
</ResponseExample>
