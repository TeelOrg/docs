<Info>**Scope** `payouts:read` · rate limit `default` (60/min, burst 20)</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

## Query parameters

<ParamField query="limit" type="integer" default="10">
  Maximum number of results. A value below 1 or not a number falls back to 10.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of results to skip.
</ParamField>

<ParamField query="recipient_id" type="string">
  Only payouts to this recipient UUID.
</ParamField>

<ParamField query="batch_id" type="string">
  Only payouts in this batch, the `batchId` from [`POST /rfq/execute-batch`](/api-reference/payouts/execute-batch).
</ParamField>

<ParamField query="status" type="string">
  Only payouts in this status: `pending`, `pending_collection`, `processing`, `completed`, `failed` or `cancelled`.
</ParamField>

<ParamField query="transaction_type" type="string">
  Only payouts of this type: `payout` or `swap`.
</ParamField>

## Response

An array of payout objects. Each has the fields below, except `estimatedArrivalAt`, `settlementSla` and `feeVsMidMarket`, which only [`GET /payouts/{id}`](/api-reference/payouts/get) serves.

## Errors

| Status | Code | When |
| --- | --- | --- |
| `400` | `FIELD_NOT_WRITABLE` | The request sends `stage` or `q`, which are not partner API parameters. |
| `400` | `INVALID_PARAMETER` | `recipient_id` or `batch_id` is not a UUID. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `payouts:read`. |
| `404` | `NOT_FOUND` | `recipient_id` names a recipient that does not exist or is not yours. |
| `429` | `RATE_LIMITED` | Per-key rate limit. Wait for `Retry-After`. |
