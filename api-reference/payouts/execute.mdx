---
title: Execute a payout
api: POST /api/rfq/execute
description: Lock a quote and start the payout in one call.
---

Locks a quote and starts the payout in one call. `flowType` picks the corridor; the tabs below show what each one needs and returns.

Response: `{ "success": true, "data": { … } }`.

<Info>**Scope** `payouts:write` · rate limit `payouts_write` (30/min, burst 10) · requires payouts to be enabled for your business</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Optional. 8–255 characters from `[A-Za-z0-9_-]`. A retry with the same key and body within 24 hours replays the first response. The same key with a different body returns `409 IDEMPOTENCY_KEY_REUSED`; a retry while the first is still running returns `409 IDEMPOTENCY_REQUEST_IN_FLIGHT`.
</ParamField>

## Request body

<ParamField body="flowType" type="string" default="fiat-to-fiat">
  `fiat-to-fiat`, `stablecoin-to-fiat` or `onramp` (fiat to stablecoin). Absent means `fiat-to-fiat`, so send it on every other corridor. Underscored spellings such as `stablecoin_to_fiat` are also accepted. Any other value is `400`.
</ParamField>
<ParamField body="fromCurrency" type="string" required>Source currency. ISO 4217 for fiat, ticker for stablecoin.</ParamField>
<ParamField body="toCurrency" type="string" required>Destination currency.</ParamField>
<ParamField body="amount" type="number" required>Source amount. Must be `> 0`.</ParamField>
<ParamField body="recipientId" type="string" required>UUID from [`POST /recipients`](/api-reference/recipients/create).</ParamField>
<ParamField body="recipientPaymentMethodId" type="string">UUID of the recipient payment method to pay, when the recipient has more than one.</ParamField>
<ParamField body="targetAmount" type="number">Exact-output target. When set, Teel sizes the source so the recipient receives this amount.</ParamField>
<ParamField body="amountMode" type="string" default="target">
  The side you fixed: `target` when you entered `targetAmount`, `source` when you entered `amount` and `targetAmount` is the quoted delivery. Any other value is `400 INVALID_PARAMETER`.
</ParamField>
<ParamField body="routeProtocol" type="string">Route token (`rt_…`) from a `/quotes/*` response. Pins that route; without it, Teel picks the best route at lock time.</ParamField>
<ParamField body="payoutRail" type="string">
  Destination rail: the chosen quote's `payoutRail`, or a `rail` from its `payoutRailOptions`. A chosen rail is never swapped for another: if no route pays it for this payout, the execute is `422 PAYOUT_RAIL_UNAVAILABLE`. A value that is not a rail of `toCurrency` is `400 INVALID_PAYOUT_RAIL`.
</ParamField>
<ParamField body="bridgingAsset" type="string">Fiat-to-fiat only. The `bridgingAsset` of the route you pin, as the quote returned it. An unknown ticker, or one sent on another `flowType`, is `400`.</ParamField>
<ParamField body="fundingRail" type="string">Held-balance sources only. The `fundingRail` of the chosen quote. A rail the source cannot fund on is `422 FUNDING_RAIL_UNSUPPORTED`.</ParamField>
<ParamField body="executionKind" type="string">`direct_bank` to pay a bank recipient from a held fiat balance without conversion. Requires `payoutRail`: `ach`, `fedwire`, `fednow`, `sepa`, `fps` or `chaps`.</ParamField>
<ParamField body="paymentPurpose" type="string">Purpose code from [`GET /payouts/payment-purposes`](/api-reference/payouts/payment-purposes).</ParamField>
<ParamField body="purposeDescription" type="string">Free-text purpose. Required, 10–255 characters, when `paymentPurpose` is `other`; otherwise `400 INVALID_PARAMETER`.</ParamField>
<ParamField body="reference" type="string">Your reference, stored on the payout and returned on reads.</ParamField>
<ParamField body="supportingDocumentFileId" type="string">
  The `fileId` from [`POST /payouts/document`](/api-reference/payouts/upload-document), for a route that asks for a document. An id that is not a document your account uploaded is `400 INVALID_PARAMETER`. See [Supporting documents](/guides/supporting-documents).
</ParamField>

<Tabs>
  <Tab title="Fiat-to-fiat">
    Send fiat from your stored payment method; the recipient receives fiat.

    <ParamField body="userPaymentMethodId" type="string" required>UUID of your funding source.</ParamField>

Poll [`GET /rfq/status/{quoteId}`](/api-reference/payouts/status) for `transactionId` (the payout id) and `bankingInstructions`. A payout funded from a held balance is the exception: it answers with `payoutId` set.

## Fees

<ResponseField name="fees.teelFee" type="number">Teel's fee on this payout.</ResponseField>
<ResponseField name="fees.teelFeeBps" type="integer">Teel's fee in basis points (1 bp = 0.01%).</ResponseField>
<ResponseField name="fees.partnerFee" type="number">Your markup. `0` unless configured.</ResponseField>
<ResponseField name="fees.gasFee" type="number">On-chain gas passed through, on stablecoin flows.</ResponseField>

## Errors

| Status | Code | When |
|---|---|---|
| `200` | `error.code`, with `success: false` | The quote could not be locked, for example `corridor_unsupported`, `amount_out_of_range` or `rate_unavailable`. Nothing was created. `error.retryable` says whether the same request can succeed later. Always check `success`. |
| `400` | `INVALID_JSON` / `INVALID_PARAMETER` | Body malformed, a required field missing, a UUID malformed, `amountMode` or `purposeDescription` invalid, or `supportingDocumentKey` sent (no longer accepted). |
| `400` | `INVALID_PAYOUT_RAIL` | `payoutRail` is not a rail of `toCurrency`. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `payouts:write`. |
| `403` | `PAYOUTS_NOT_ENABLED` | Payouts are not enabled for your business. |
| `403` | `APPROVAL_REQUIRED` | Your business approves payouts before they execute, so this route cannot commit one in a single call. |
| `403` | `FORBIDDEN` | A currency is outside your business's payouts scope. |
| `404` | `RECIPIENT_NOT_FOUND` / `PAYMENT_METHOD_NOT_FOUND` | A recipient or payment method does not exist or is not yours. |
| `409` | `IDEMPOTENCY_KEY_REUSED` / `IDEMPOTENCY_REQUEST_IN_FLIGHT` | Idempotency conflict. For in-flight, wait for `Retry-After`. |
| `409` | `rate_moved` / `route_infeasible`, nested in `error` | The price moved past your tolerance, or the pinned route can no longer carry the payout. Nothing was locked; get a new quote. See [Errors](/errors#conflicts). |
| `422` | `PAYOUT_RAIL_UNAVAILABLE` | No route pays the `payoutRail` you chose for this payout. |
| `422` | See [Business rules](/errors#business-rules) | The payout breaks a business rule, for example `HELD_BALANCE_INSUFFICIENT`, `SUPPORTING_DOCUMENT_REQUIRED`, `FUNDING_RAIL_UNSUPPORTED` or `RECIPIENT_VERIFICATION_PENDING`. |
| `429` | `RATE_LIMITED` | `payouts_write` budget exhausted. Wait for `Retry-After`. |
| `502` / `503` | `DOWNSTREAM_UNAVAILABLE` | The payout engine could not be reached. Retry with the same `Idempotency-Key`. |
