title: Delete Payout
api: DELETE /api/payouts/{id}

<Note>

</Note>

</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Payout ID.
</ParamField>
## Response

<ResponseExample>
```json
{
  "success": true
}
```

</ResponseExample>
