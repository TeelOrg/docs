---
title: Check whether a payout can be retried
api: GET /api/payouts/{id}/retryable
description: Whether a stalled payout step can be retried, and what is blocking it.
---

Retrying a payout is done from the Teel dashboard; there is no partner API for it. Use this endpoint to see whether a stalled payout is eligible.

<Info>**Scope** `payouts:read` · rate limit `default` (60/min, burst 20)</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

<ParamField header="X-Teel-Entity-Id" type="string">
  Only needed when the key's owner belongs to more than one business. The UUID of the business this request acts for. Without it, such a key gets `400 ENTITY_REQUIRED`.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Payout `transactionId` from [`POST /rfq/execute`](/api-reference/payouts/execute).
</ParamField>

## Response

<ResponseField name="success" type="boolean">Always `true` on `200`.</ResponseField>
<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="retryable" type="boolean">`true` when a retry would run now.</ResponseField>
    <ResponseField name="action" type="string">
      The step a retry would re-run: `retry_onramp`, `retry_compliance`, `retry_offramp`, or `retry_settle`. Omitted when the payout is not stalled.
    </ResponseField>
    <ResponseField name="detector" type="string">Which stall check matched, for example `converting_offramp_stalled`. Omitted when none matched.</ResponseField>
    <ResponseField name="reason" type="string">Why the payout counts as stalled. Omitted when none matched.</ResponseField>
    <ResponseField name="blockedBy" type="string">What prevents the retry, for example `corrected`. Omitted when nothing blocks it.</ResponseField>
  </Expandable>
</ResponseField>

When no stall check matches, `data` is `{"retryable": false}`.

### Errors

| Status | `code` | When |
|---|---|---|
| `400` | `INVALID_PARAMETER` | `id` is not a UUID. |
| `400` | `ENTITY_REQUIRED` | The key's owner belongs to more than one business and `X-Teel-Entity-Id` is missing. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `payouts:read`. |
| `404` | `NOT_FOUND` | The payout does not exist, is not yours, or has not been released yet. All three answer the same. |
| `429` | `RATE_LIMITED` | Per-key rate limit exhausted. Wait for `Retry-After`. |
