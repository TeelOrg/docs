---
title: Get quote status
api: GET /api/rfq/status/{quoteId}
description: Where a locked quote, and the payout it started, stands.
---

Look up the quote from [`POST /rfq/execute`](/api-reference/payouts/execute) by its `quoteId`. This is where a fiat-to-fiat payout's id (`transactionId`) and deposit instructions appear. For the payout itself, read [`GET /payouts/{id}`](/api-reference/payouts/get) or subscribe to [Webhooks](/guides/webhooks).

<Info>**Scope** `payouts:read` · rate limit `default` (60/min, burst 20)</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

## Path parameters

<ParamField path="quoteId" type="string" required>UUID of the locked quote.</ParamField>

## Response

Fields fill in as the payout progresses.

<ResponseField name="quoteId" type="string">Echoed back.</ResponseField>
<ResponseField name="status" type="string">
  The quote lock's status, not the payout's:

  | Status | Meaning |
  |---|---|
  | `pending` | Created, not yet accepted. |
  | `accepted` | Locked; the payout is starting. |
  | `awaiting_deposit` | Stablecoin-to-fiat: waiting for your deposit to `escrowAddress`. |
  | `deposit_confirming` | Deposit seen, waiting for confirmations. |
  | `webhook_processing` | The collected stablecoin has arrived and settlement is starting. |
  | `processing` | Settlement is under way. |
  | `completed` | Settled for the quoted amount. |
  | `completed_with_topup` | Settled; the delivery fell short and was topped up. |
  | `completed_with_surplus` | Settled; the delivery came in above the quote. |
  | `cancelled` | Cancelled before settlement. |
  | `onramp_abandoned` | The collection never arrived and the payout was abandoned. |
  | `expired` | The lock lapsed before it was used. |
  | `failed` | The payout failed; see `errorMessage`. |

  Treat any other value as in progress.
</ResponseField>
<ResponseField name="transactionId" type="string">UUID of the payout. Use it with [`GET /payouts/{id}`](/api-reference/payouts/get). Set once the payout exists.</ResponseField>
<ResponseField name="quotedToAmount" type="number">Destination amount quoted at lock time.</ResponseField>
<ResponseField name="actualToAmount" type="number">Destination amount actually delivered. Set after delivery; absent when none was reported.</ResponseField>
<ResponseField name="deltaAmount" type="number">Signed `actualToAmount − quotedToAmount`.</ResponseField>
<ResponseField name="settleTxHash" type="string">On-chain settlement transaction hash.</ResponseField>
<ResponseField name="onrampProvider" type="string">Route token (`rt_…`) of the collection leg.</ResponseField>
<ResponseField name="offrampProvider" type="string">Route token (`rt_…`) of the delivery leg.</ResponseField>
<ResponseField name="paymentUrl" type="string">Hosted payment page, on routes that collect through one.</ResponseField>
<ResponseField name="bankingInstructions" type="object">Map of `string` to `string` with the bank details to pay, on routes that collect by bank transfer.</ResponseField>
<ResponseField name="escrowAddress" type="string">Stablecoin-to-fiat: the wallet to send the deposit to. Set while `status` is `awaiting_deposit`.</ResponseField>
<ResponseField name="depositAmountAtomic" type="string">Stablecoin-to-fiat: amount to send, as an atomic-units integer string. Parse with `BigInt`.</ResponseField>
<ResponseField name="tokenAddress" type="string">Stablecoin-to-fiat: contract address of the source stablecoin.</ResponseField>
<ResponseField name="chainId" type="integer">Stablecoin-to-fiat: chain id of `escrowAddress`.</ResponseField>
<ResponseField name="settlementChainId" type="integer">Chain the payout's stablecoin settles on. `0` when not set.</ResponseField>
<ResponseField name="actualUsdcReceived" type="string">USDC received for this quote, as an atomic-units integer string. Parse with `BigInt`. `"0"` until measured, and on a payout inside a batch.</ResponseField>
<ResponseField name="batchActualUsdcReceived" type="string">Batch payouts only: USDC received for the whole batch's collection, atomic-units integer string.</ResponseField>
<ResponseField name="errorMessage" type="string">Set when `status` is `failed`.</ResponseField>

## Errors

| Status | Code | When |
|---|---|---|
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `payouts:read`. |
| `404` | none | The quote does not exist or is not yours. Body: `{"success": false, "error": "…"}`. |
| `429` | `RATE_LIMITED` | Per-key rate limit. Wait for `Retry-After`. |
| `502` | `DOWNSTREAM_UNAVAILABLE` | The payout engine could not be reached. Retry. |
