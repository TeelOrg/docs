---
title: Get batch collection
api: GET /api/payouts/batch/{batchId}/collection
description: The single pay-in that funds every payout in a batch.
---

A batch payout is funded by one collection (onramp). This returns it, including the deposit instructions you pay against.

<Note>
  The top-level keys of this response are snake_case. The keys inside `metadata` are camelCase.
</Note>

<Info>**Scope** `payouts:read` · rate limit `default` (60/min, burst 20)</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  API key.
</ParamField>

<ParamField header="X-Teel-Entity-Id" type="string">
  Only needed when the key's owner belongs to more than one business. The UUID of the business this request acts for. Without it, such a key gets `400 ENTITY_REQUIRED`.
</ParamField>

## Path parameters

<ParamField path="batchId" type="string" required>
  Batch UUID: the `batchId` in the `202` response of [`POST /rfq/execute-batch`](/api-reference/payouts/execute-batch).
</ParamField>

### Errors

| Status | `code` | When |
|---|---|---|
| `400` | `INVALID_PARAMETER` | `batchId` is not a UUID. |
| `400` | `ENTITY_REQUIRED` | The key's owner belongs to more than one business and `X-Teel-Entity-Id` is missing. |
| `401` | `UNAUTHORIZED` | Missing or invalid key. |
| `403` | `INSUFFICIENT_SCOPE` | Key lacks `payouts:read`. |
| `404` | `NOT_FOUND` | No collection exists for this batch yet, or the batch is not yours. Both answer the same. |
| `429` | `RATE_LIMITED` | Per-key rate limit exhausted. Wait for `Retry-After`. |
